Задание 01

Как открывается страница

Получение данных:
1. Пишу в браузере адрес example.com и нажимаю Enter.
2. Браузер через DNS узнаёт IP адрес сайта.
3. Браузер подключается к серверу и отправляет запрос GET.
4. Сервер присылает ответ: статус и HTML.

Отображение:
5. Браузер читает HTML и CSS.
6. Браузер показывает страницу на экране, а JavaScript делает её интерактивной.

Frontend это то, что работает в браузере. Backend это программа на сервере, она отвечает на запросы. HTTP это правила, по которым браузер и сервер общаются.

Примеры (кнопка)

HTML, сама кнопка:
<button id="btn">Нажми</button>

CSS, цвет текста:
#btn { color: red; }

JavaScript, что будет при нажатии:
document.getElementById('btn').onclick = function () { alert('Привет'); };

Запрос из Network

Адрес: https://example.com/
Метод: GET
Статус: 200
Content-Type: text/html
